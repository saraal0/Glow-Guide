# Glow Guide
A skincare analysis program developed using **MIPS Assembly** as part of an academic project.

## Features

- Collects and confirms the user's name.
- Asks multiple-choice questions about skin characteristics.
- Validates user input.
- Determines a skin type based on the user's answers.
- Provides a suggested skincare routine.
- Allows users to restart the assessment.

## Technologies

- MIPS Assembly
- MARS MIPS Simulator
